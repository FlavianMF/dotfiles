# Modo: desenvolvimento

Sessão de implementação. O objetivo é código funcionando, testado e commitado em passos
pequenos.

- Antes de editar, localize o ponto de mudança e o teste que o cobre; se não houver
  teste, escreva o teste primeiro quando o comportamento for verificável.
- Trabalhe em fatias verticais: uma mudança, rodar os testes do escopo, commit.
- Rode lint/typecheck do projeto antes de declarar a etapa pronta.
- Etapa pronta = testes do escopo verdes, diff revisado, commit feito (ou pronto para
  commit, se o usuário não pediu commit).
- Ao fim de cada etapa, diga em uma linha o que mudou e qual é a próxima.
